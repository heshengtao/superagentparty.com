# superagentparty.com

这是我的个人作品集站点 —— 关于我做的一些开源作品，以及它们想解决的问题。

## 我是谁

我是 **heshengtao**，一个相信「AI 应该属于每个人的」的人。它不该被锁在某个云端账号里，而应该能被下载、被修改、被真正拥有。

所以这些年我做的事情，大多围绕同一个念头：让一个人也能用上完整的 AI 能力。

## 我做了什么

- **Super Agent Party** —— 一个全能 AI 伴侣。给它一副嗓子、一双眼睛和一个身体，它就能陪你聊天、开直播、打游戏、管智能家居。
- **ComfyUI LLM Party** —— 把大模型、智能体、语音和图像生成放进同一张画布，用拖拽就能搭出一个完整的 AI 应用。
- **Exameow** —— 上传课件和教材，几秒生成一整套试卷，还带练习模式和错题本。
- **LabelAll** —— 打开一个文件夹，就能直接查看和标注图像数据集。

此外还有围绕它们生长出的插件、扩展与教程，大大小小三十来个仓库。
