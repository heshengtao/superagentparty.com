# 星球树木风格改造设计

状态：方向已确认，待进入实现计划。

## 目标

将星球场景中现有的“圆柱树干 + 单个锥形树冠”统一改为参考图所示的柔和、分层、手工感低多边形树木。改造覆盖树冠轮廓、枝干比例、明暗层次和配色，同时保留当前球面贴合、低多边形轮廓和批量合并的渲染结构。

## 视觉方案

每棵树由四类几何组成：

- 略微收窄的多边形树干，颜色保持灰棕色但增加明暗变化。
- 树干只在最低冠层下方短距离露出，避免枝杈形成外露木棍。
- 3–5 个错位的低多边形树冠单元，组成不规则、圆润的整体轮廓。
- 少量浅色冠层作为受光面，深色冠层作为内层和下层阴影。

树冠单元使用低细分 Icosahedron 或低边数圆锥的组合，单元之间有轻微的水平偏移、垂直错层、旋转和缩放变化。随机变化由现有种子随机数生成器驱动，保证相同项目和种子下结果稳定。主星使用更高、更宽的树，卫星根据星球半径自动缩小冠层。

## 实现边界

改动集中在 `src/planet.js` 的树木生成逻辑和材质表，不改变项目数据、相机、交互或页面文案。继续通过 `fragment` 将树木部件加入材质桶，再由 `flush` 合并，避免每棵树产生独立 draw call。需要新增或调整的材质名称保持可测试、可读，并沿用现有的 `tree`、`treeLight`、`trunk` 命名体系；如增加阴影层，使用明确的 `treeShadow` 材质。

所有主星与卫星继续调用同一个 `makeForest`/`makeTree` 路径。树木尺寸根据 `radius` 缩放，避免小卫星上的冠层互相穿插或遮挡项目地标。

## 验收标准

- 树木不再呈现单一尖锥树冠，而是有清晰的分层、错位和圆润不规则轮廓。
- 短树干和树冠在参考图所需的柔和低多边形配色中保持可辨识的明暗层次，树冠主体不被木质几何打断。
- 主星和卫星都使用新树形；同一种子生成结果稳定，不出现 NaN 或无穷坐标。
- 主星 drawables 数量仍低于现有测试阈值，树木继续按材质批量合并。
- 现有项目选择、旋转、缩放和降级路径不受影响。
- `npm test` 与 `npm run build` 通过，并用浏览器截图检查树冠遮挡、球面贴合和移动端缩放。

## 不在范围内

不增加贴图、后处理、粒子树叶、外露枝杈、风动画或独立树木交互；不改变星球布局、建筑造型和页面整体配色。
