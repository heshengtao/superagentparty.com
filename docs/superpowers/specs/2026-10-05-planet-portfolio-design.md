# 迷你星球作品集设计提案

状态：待用户确认方向，尚未进入实现。

## 目标与依据

将 heshengtao 的个人作品集做成可探索的微缩星球世界。每个仓库对应一颗星球，生态仓库作为所属主项目的卫星，点击即可了解作品并进入源码或在线演示。

内容依据为当前 README.md 的中英双语资料。视觉依据为 https://messenger.abeto.co/ 的公开页面及官方 social.jpg：青绿背景、环绕球面的小镇、低多边形几何、低饱和草木与建筑、深色轮廓、分层阴影。已查看官方封面，尚未验证游戏内完整交互；不将推测描述为参考游戏的实际功能。

保留现有 README、LICENSE 和工作区变更，不恢复已删除的旧实现。新场景采用自行创建的几何模型和材质。

## 方案比较

1. **推荐：可探索星图 + 星球近景。** 首页同时呈现主星与生态卫星；选择星球后镜头靠近，可旋转欣赏球面建筑并打开作品详情。兼顾用户要求的仓库关系和参考作品的微缩世界视觉。
2. **单星球逐个切换。** 每次只展示一个精细星球，更容易集中画面细节，但生态关系不够直观。
3. **角色漫游。** 在球面上控制角色到访项目地标，游戏感更强，但增加操作门槛及动画、碰撞开发量，不作为首版方案。

## 推荐方案的视觉

- 全屏 Three.js 场景，弱透视镜头，保留球面纵深及清晰轮廓。
- 色彩：青绿背景 #80BCBB、草地 #8FA67A、深绿树冠 #52766A、石灰岩 #C5C6AD、屋顶陶红 #BD745B、轮廓炭灰 #41474B。背景避免密集装饰，给星球留出辨识空间。
- 使用 low-poly 地形、树木、房屋、桥梁和小型地标；通过平面法线、有限明暗色阶、轮廓线形成三渲二效果。卫星使用相同造型语言、较低几何复杂度。
- 主标题采用粗黑圆润无衬线字形、浅色填充与深色短投影；正文采用清晰中文无衬线字体，项目英文名称保留原样。
- 首屏以 Super Agent Party 与 ComfyUI LLM Party 两颗旗舰主星为视觉中心，Exameow 与 LabelAll 是较小的独立星球。生态卫星围绕所属主星分布，轨道仅在选中星系时轻量显示。
- Super Agent Party 为伙伴小镇；ComfyUI LLM Party 为由桥梁连接的工作坊；Exameow 为校园与书屋；LabelAll 为带彩色方块和取景框地标的工作室。造型差异服务项目辨识。

## 内容与星球关系

四颗主星使用 README 已有的简介、统计、亮点、语言、许可证、源码和演示链接。

ComfyUI LLM Party 的卫星：Let-LLM-party、comfyui_LLM_mafia、comfyui_LLM_schools。

Super Agent Party 的卫星：sap-live2d、sap-story-adventure、sap-web-preview、desktop-for-sap、sap-aigalgame、sap-example、sap-aieditor、sap-remote。

topics-after-party 暂按独立工具星球展示，README 未明确它的归属，数据结构允许后续调整。

README 的 30 个仓库及 5,243 星标作为既有统计快照，不标注为实时数据。当前仅有 16 个明确名称，因此首版展示这 16 个，不虚构另外 14 个。其余仓库通过 GitHub 全部仓库入口访问。

## 布局与交互

- 顶部：heshengtao 身份标识、作品目录、关于、中英切换、GitHub。
- 中央：星图为主要内容，首次访问出现简短探索提示。拖动旋转视角，滚轮缩放；点击星球选中并平滑推进镜头，悬停或键盘聚焦显示项目名称。
- 桌面右侧项目面板展示简介、统计、核心亮点以及源码、演示入口，支持关闭和 Escape 返回。切换项目时更新同一面板。
- 底部提供返回全景与运动开关；没有实际音频功能时不设置声音按钮。
- 作品目录包含所有已知仓库，并支持直接选中对应星球。所有仓库都能通过常规 HTML 控件访问。
- 关于面板使用 README 的个人介绍、技术栈和外部链接。
- 手机端减少同时展示的标签与装饰，详情使用底部面板；触摸旋转、选择和关闭均有明确操作入口。

## 实现边界

采用 Vite + Three.js 与原生 HTML/CSS/JavaScript，输出静态网站；无需后端服务。README 中旧版“零构建依赖”属于旧技术文案，新版如展示技术信息应与实际实现一致。

模块分为仓库数据与翻译、星球几何生成、场景与镜头、HTML 面板及输入交互。通过项目 ID 连接几何对象和内容，避免将文案写进渲染代码。

场景初始化失败或 WebGL 不可用时展示可访问的作品目录及链接。限制设备像素比，复用几何和材质，页面隐藏时暂停渲染；尊重减少动态效果设置，提供主动关闭持续运动的入口。

首版不实现角色行走、任务、积分或第三方仓库实时同步。

## 验收

- 视觉具有真实球面建筑和地形、低多边形轮廓、青绿背景及卡通色阶。
- 已知 16 个仓库全部可访问，主项目与生态卫星关系正确。
- 点击、拖动、缩放、返回全景、面板关闭、中英切换及外部链接有效。
- 键盘可完成项目选择与关闭面板；减少动态效果设置生效。
- 验证桌面和手机尺寸，无阻挡核心操作的重叠和横向溢出。
- 构建通过；浏览器无未处理异常；检查 WebGL 不可用时的内容降级。
- 使用实际浏览器截图检查球面几何、轮廓、遮挡和文字可读性。

## 自检

明确区分已核实的参考视觉与尚未体验的游戏交互；明确区分已有统计与已知项目数量；生态归属不明确的工具不强行分组。首版范围限定为静态作品集和星球浏览，暂无需要外部账号或后端部署的依赖。
